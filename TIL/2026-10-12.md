# 마지막 두 원소 (프로그래머스 Lv.0)

## 문제 요약
정수 배열 `num_list`의 마지막 원소가 그 전 원소보다 크면 `마지막 - 그전`을,
그렇지 않으면 `마지막 * 2`를 배열 끝에 추가해서 반환한다.

```
[2, 1, 6]        → [2, 1, 6, 5]        (6 > 1 → 6 - 1)
[5, 2, 1, 7, 5]  → [5, 2, 1, 7, 5, 10] (5 > 7 아님 → 5 * 2)
```

## 풀이 코드
```java
import java.util.Arrays;

class Solution {
    public int[] solution(int[] num_list) {
        int n = num_list.length;
        int[] answer = Arrays.copyOf(num_list, n + 1);   // 마지막 칸은 0으로 채워짐

        int last = num_list[n - 1];
        int prev = num_list[n - 2];
        answer[n] = last > prev ? last - prev : last * 2;

        return answer;
    }
}
```

## 핵심 포인트

### 1. 자바 배열은 크기를 늘릴 수 없다
배열은 한 번 만들면 길이가 고정된다. 원소를 "추가"하려면
**더 큰 배열을 새로 만들고 기존 값을 복사**해야 한다.

### 2. `Arrays.copyOf(원본배열, 새길이)` (처음 본 것)
원본 배열을 복사해서 **지정한 길이의 새 배열**을 만들어 준다.

```java
int[] arr = {1, 2, 3};

int[] bigger  = Arrays.copyOf(arr, 5);  // [1, 2, 3, 0, 0]  → 늘어난 칸은 기본값(0)
int[] same    = Arrays.copyOf(arr, 3);  // [1, 2, 3]        → 그냥 복사
int[] smaller = Arrays.copyOf(arr, 2);  // [1, 2]           → 뒤가 잘림
```

- 늘어난 칸은 타입의 기본값으로 채워진다 (`int` → 0, `boolean` → false, 객체 → null)
- `import java.util.Arrays;` 필요
- 원본 배열은 바뀌지 않는다 (새 배열을 반환)

`copyOf`를 몰랐다면 이렇게 직접 해야 한다:
```java
int[] answer = new int[n + 1];
for (int i = 0; i < n; i++) {
    answer[i] = num_list[i];
}
```

### 3. 마지막 원소 인덱스
길이가 `n`이면 마지막은 `n - 1`, 그 전은 `n - 2`.
새 배열의 마지막 칸(추가할 자리)은 인덱스 `n`.

### 4. 삼항 연산자
```java
조건 ? 참일 때 값 : 거짓일 때 값
```
if-else를 한 줄로 줄일 때 사용.

## 참고: 비슷한 메서드
| 메서드 | 용도 |
|---|---|
| `Arrays.copyOf(arr, len)` | 처음부터 len 길이만큼 복사 |
| `Arrays.copyOfRange(arr, from, to)` | from ~ to-1 구간만 복사 |
| `Arrays.toString(arr)` | 배열 내용을 `[1, 2, 3]` 형태 문자열로 (출력 확인용) |

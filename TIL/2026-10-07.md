# 2026-10-07 프로그래머스 코딩 테스트 정리

## 1. 문자 리스트를 문자열로 변환하기 — `String.join`
```java
return String.join("", arr);
```
- `String.join(구분자, 배열)` : 배열 요소를 구분자로 이어 붙여 하나의 문자열로 만듦
- `String.join("", {"a","b","c"})` → `"abc"`
- `String.join(", ", {"a","b","c"})` → `"a, b, c"`

## 2. 홀짝 구분하기 — 삼항 연산자 + Scanner
```java
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
System.out.print(n + " is " + (n % 2 == 0 ? "even" : "odd"));
```
- 삼항 연산자 : `조건 ? 참일 때 값 : 거짓일 때 값`
- 문자열 연결 안에서 쓸 때는 괄호로 감싸야 함
  - 괄호가 없으면 문자열이 먼저 합쳐진 뒤 비교되어 에러
- `Scanner` : `import java.util.Scanner;` 필요

## 3. 문자열 곱하기 — `String.repeat`
```java
return my_string.repeat(k);
```
- `문자열.repeat(n)` : 문자열을 n번 반복
- `"ab".repeat(3)` → `"ababab"`
- Java 11부터 사용 가능

## 4. 더 크게 합치기 — `Integer.parseInt` + 삼항 연산자
```java
int aLong = Integer.parseInt("" + a + b);
int bLong = Integer.parseInt("" + b + a);
return aLong > bLong ? aLong : bLong;
```
- int → String : `"" + a` 또는 `String.valueOf(a)`
- String → int : `Integer.parseInt(str)`
- `"" + a + b` → 문자열 이어붙이기 / `a + b + ""` → 숫자 덧셈 먼저
- `a.toString()` ❌ : int는 기본형이라 메서드 없음
- `(int)"123"` ❌ : 형변환은 숫자 타입끼리만 가능
- 더 간단하게 : `Math.max(Integer.parseInt("" + a + b), Integer.parseInt("" + b + a))`

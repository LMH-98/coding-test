# 2026-10-06 프로그래머스 코딩 테스트 리뷰

## Java 제곱 / 최대·최소 비교
- `Math.pow(x, 2)` : 제곱 (반환형 double → int로 쓰려면 형변환)
- `Math.max(a, b)`, `Math.min(a, b)` : 두 값 중 큰 값 / 작은 값

int b_square = (int)(Math.pow(Math.max(a, c), 2) - Math.pow(Math.min(a, c), 2));

- 정수 제곱은 `x * x`가 더 간단하고 오차가 없음

## 코드 리뷰하는 방법
1. 구체적인 예시 입력을 정한다.
2. 그 값으로 코드를 한 줄씩 따라가며 변수 값을 추적한다.
3. 기대한 결과와 달라지는 지점을 찾는다.
4. 원하는 결과가 나오도록 어떻게 고칠지 단계별로 생각한다.

> 한 번에 고쳐지는 건 이미 답을 알고 있는 문제뿐이다.
> 모르는 문제는 단계별로 추적하는 수밖에 없다.
